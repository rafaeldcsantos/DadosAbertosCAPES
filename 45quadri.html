Como calcular

A base usada é Data/discentes_ingressantes_por_ano_area.csv, gerada a partir de RawData/br-capes-colsucup-discentes-*.xlsx com filtro ST_INGRESSANTE = SIM. O indicador principal desta página é CONTAGEM_INGRESSANTES_ID_PESSOA (ID de aluno distinto por ano e área).

Observação: este é um proxy de fluxo de entrada anual no sistema CAPES, não um censo de todos os matriculados.
