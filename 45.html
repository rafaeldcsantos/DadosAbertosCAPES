Sobre este Documento

Esta página é um índice de perguntas e respostas sobre a Área 45 (Interdisciplinar). Cada pergunta abre uma página própria com conteúdo textual, detalhes sobre o processamento dos dados (para verificação e reprodutibilidade) e gráfico(s).

Sobre os Dados

As fontes de dados usadas para os gráficos e relatórios são:

  • Portal de Dados Abertos da CAPES, em particular a base de avaliação da pós-graduação stricto sensu.
  • Tabelas coletadas das planilhas de dados abertos, com anotações.
  • Web scraping da antiga plataforma Sucupira.

Nenhum dado proprietário ou privado foi usado.
