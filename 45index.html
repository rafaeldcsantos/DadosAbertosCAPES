Sobre este Documento

Esta página é um índice de perguntas da Área 45. Cada pergunta abre uma página própria com conteúdo textual, receita de dados e gráfico(s).

Sobre os Dados

As fontes de dados usadas para os gráficos e relatórios são:

  • Portal de Dados Abertos da CAPES, em particular a base de avaliação da pós-graduação stricto sensu.
  • Web scraping da antiga plataforma Sucupira quando necessário.

Nenhum dado proprietário ou privado foi usado.
