Metodologia (conservadora com base histórica)

  1. Proxy histórico: em cada arquivo RawData/Teses/dados_YYYY.xlsx, contar registros com AreaAvaliacao = INTERDISCIPLINAR (1999-2012).
  2. Sobreposição para calibração: comparar o proxy com Data/discentes_egressos_por_ano_area_desde2004.csv (Área 45) em 2004-2012.
  3. Razão anual de calibração: ratio = egressos_discentes / teses_interdisciplinar.
  4. Tratamento robusto: marcar outlier por IQR (2010) e removê-lo do cálculo do fator.
  5. Fator conservador aplicado em 1999-2003: mínimo dos anos não-outlier f = min(ratio_limpo) = 0,970722.
  6. Série final: EGRESSOS_RECONSTRUIDOS = floor(TESES_INTERDISCIPLINAR * f) para 1999-2003; 2004-2024 mantido como observado em discentes.

Como os dados foram coletados e analisados

1) Para cada ano de 1999 a 2012, foi aberto o arquivo RawData/Teses/dados_YYYY.xlsx e lida a planilha principal (dados_YYYY) em modo somente leitura, para reduzir custo de memória.

2) Nessas planilhas, foi usada a coluna AreaAvaliacao. A contagem anual do proxy foi feita com correspondência exata AreaAvaliacao = INTERDISCIPLINAR. Isso gera a série bruta histórica (teses/dissertações) para a área.

3) Em seguida, foi feita a sobreposição com a série de referência Data/discentes_egressos_por_ano_area_desde2004.csv para os anos 2004-2012 (onde ambas as fontes coexistem). Para cada ano, foi calculado ratio = egressos_discentes / teses_interdisciplinar.

4) Os ratios anuais passaram por triagem robusta com IQR para detectar anomalias; 2010 foi marcado como outlier e removido da base de calibração.

5) O fator aplicado na reconstrução foi deliberadamente conservador: o menor ratio entre anos limpos (f = 0,970722). Com isso, 1999-2003 foi estimado por floor(proxy_teses * f), evitando superestimação.

6) A série final 1999-2024 mantém os valores observados de 2004-2024 sem suavização e usa estimativa apenas em 1999-2003. Os arquivos derivados gerados para auditoria são: Data/egressos_area45_reconstruido_1999_2024.csv e Data/egressos_area45_teses_overlap_2004_2012.csv.
